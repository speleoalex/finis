This page lists the pages of the site in the order they appear in the menu. An indented page is a child of the page above it.

Moving a page

  • Drag a page by the handle on the left (☰), with the mouse or with a finger. Child pages follow the page you move.
  • Or use the buttons: ▲ and ▼ swap the page with the one above or below it at the same level (they stay off when there is nowhere to go), ► makes it a child of the one above, ◄ moves it back up one level.
  • When a page leaves a group with ◄, the pages that followed it at the same level become its children: if that is not what you want, move it to the end of the group with ▼ first.
  • With the keyboard: focus the handle and use the four arrow keys.

Changes stay in the page until you press Save in the bar at the bottom. While there are unsaved changes the bar says so, and the browser warns you if you try to leave.

The buttons on each row

PHP, IT, EN
Open the content of the page: PHP is the code, the language codes are the texts. A solid green box means the file is already there, a dashed one means it will be created.
💡
Hides the page from the menu, or puts it back. The page is still reachable at its own address: this takes it out of the navigation, it does not protect it.
⚙
Settings of the page: title, type, allowed groups, publication dates.
✕
Deletes the page and its folder. This cannot be undone.

The badges next to the name

  • 🔒 minimum level required to see the page.
  • 🔑 groups allowed to view, ✎ groups allowed to edit.
  • 🔐 restrictions coming from the page type (for example the groups of a dbview section).
  • 📅 publication start and end dates.
  • A struck out name is a disabled page, a faded italic one is hidden from the menu.

The name of the page is a link: open it to preview the page on the site in a new tab.
